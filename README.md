# LogLens

LogLens — небольшая Bash-утилита для быстрой проверки лог-файлов. Она показывает сведения о файле и первые строки, находит уникальные IPv4-адреса и сохраняет простой текстовый отчёт. Была создана с целью практики скриптинга на Bash.

## Требования

- Bash;
- GNU-совместимые утилиты `wc`, `grep`, `awk` и `sort`.

В Windows скрипт можно запускать через WSL или Git Bash.

## Быстрый старт

```bash
cd bash-lab
chmod +x bash-lab.sh
./bash-lab.sh help
```

Формат команды:

```bash
./bash-lab.sh <режим> <путь-к-логу>
```

## Режимы

| Режим | Что делает |
| --- | --- |
| `help` | Показывает справку. Путь к логу не нужен. |
| `info` | Показывает версию, имя файла и количество строк. |
| `preview` | Выводит первые пять строк с нумерацией. |
| `scan` | Выводит уникальные IPv4-адреса. |
| `report` | Создаёт `report.txt`, а ошибки записывает в `error.log`. |

Примеры:

```bash
./bash-lab.sh info sample.log
./bash-lab.sh preview sample.log
./bash-lab.sh scan sample.log
./bash-lab.sh report sample.log
```

Файлы `report.txt` и `error.log` создаются в текущем каталоге и перезаписываются при следующем запуске режима `report`.
